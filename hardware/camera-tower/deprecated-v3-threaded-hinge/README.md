# Deprecated V3 threaded hinge

The V4 design replaces the oversized diamond-bore hinge and printed PLA-CF
fastener set in this directory. Do not print these files; they unnecessarily
change the camera enclosure.

Use `../so101_cam_tower_silk_v4_tilt_head_upgrade_ams_p2s.3mf` instead. V4
retains the previously printed V2 camera enclosure and uses a round 3.4 mm bore
with a metal M3 x 40 bolt.
